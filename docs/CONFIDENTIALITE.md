# IdlePort : politique de confidentialité

Dernière mise à jour : 27 octobre 2026.

IdlePort est un jeu mobile. Cette page explique quelles données il utilise.

## Votre partie

Votre partie est enregistrée **uniquement sur votre téléphone**. Elle n'est envoyée à personne. Vous pouvez l'exporter vous-même (Réglages > Sauvegarde) sous forme d'un code que vous gardez où vous voulez.

## Statistiques anonymes (facultatives)

Si vous l'acceptez (question posée dans le jeu, modifiable dans les Réglages), le jeu envoie des statistiques **anonymes** : missions atteintes, durée des sessions, niveau, erreurs techniques. Elles sont liées à un identifiant aléatoire créé par le jeu, jamais à votre nom, e-mail ou téléphone. Elles servent uniquement à améliorer le jeu et ne sont ni vendues ni partagées.

## Publicités et achats

Les publicités sont toujours facultatives et récompensées. Quand elles seront actives, elles seront fournies par Google AdMob, qui peut utiliser l'identifiant publicitaire de votre appareil selon vos choix de consentement (fenêtre affichée au premier lancement en Europe) : https://policies.google.com/technologies/ads. Les achats intégrés passent par Google Play ; IdlePort ne voit jamais vos informations de paiement.

## Notifications

Les rappels (avion rentré, cadeau du jour…) sont des notifications locales programmées par le jeu sur votre téléphone. Aucune donnée n'est envoyée pour cela. Vous pouvez les couper dans les Réglages.

## Enfants

IdlePort ne collecte pas sciemment de données personnelles d'enfants.
